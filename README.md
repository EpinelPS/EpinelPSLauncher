# EpinelPS Launcher

Discord server: https://discord.gg/Ztt6Y9vQjF

> [!WARNING]
> Please note that if you select "Official server", the launcher will communicate with LevelInfinite's servers. Additionally, you may be banned as this launcher currently does not behave the same way as the official one. Only email and password login is supported.

## NOTE
This project is provided "as is", I am not responsible for your account being banned if you choose to use this launcher on the official server.

## Usage
[Windows download link](https://nightly.link/EpinelPS/EpinelPSLauncher/workflows/build/master/Launcher_win-x64.zip).

[Linux download link](https://nightly.link/EpinelPS/EpinelPSLauncher/workflows/build/master/Launcher_linux-x64.zip).

Extract the zip file somewhere, and run EpinelPSLauncher.exe (or chmod +x EpinelPSLauncher and than EpinelPSLauncher if on Linux).

## Features
 - Run the game without any of the original launcher files
 - Download/update the game faster than the official Launcher
 - Ability to change asset location
 - Linux support
